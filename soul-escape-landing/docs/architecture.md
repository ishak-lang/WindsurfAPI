# Soul Escape Architecture

- Next.js App Router with locale segment (`/ar`, `/en`) and RTL/LTR rendering.
- Tailwind + glassmorphism cards + serene color tokens.
- API routes for booking and wellness quiz recommendations.
- Prisma/PostgreSQL schema for users, retreats, bookings, and quiz outcomes.
- SaaS-ready split between public pages, user dashboard, and admin dashboard.
